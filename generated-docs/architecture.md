## Conventions
- Signed-in views live under `web/src/app/(app)/<route>/page.tsx`; routes: `/overview`, `/file-log`, `/curve-data`, `/yield-curves`, `/workflow-monitor`, `/api-reference` (not `/api`), plus the import trace `/file-log/imports/[woid]`. `/` redirects to `/overview`.
- Each view renders exactly one `<h1>` (via `PageHeader`); the frame owns the only `<main>`, `<header>` and `<nav>` landmarks.
- Colours come from tokens in `globals.css`: Genwood primitives `--gw-*`, Shadcn semantics, plus `brand*`, `selected*`, `border-subtle`, `chart-1..6`, chart furniture `chart-grid` / `chart-axis` / `chart-label`, status intents `{success,warning,danger,info,neutral}` / `-surface` / `-border`, `toast*`; layout sizes `--layout-*` (incl. `--layout-table-max-height` 520px for scrolling table cards: wrap the Shadcn `Table` in a `max-h-(--layout-table-max-height) overflow-auto` div with `[&>[data-slot=table-container]]:overflow-visible` so `sticky top-0` headers work); type tokens `text-page-title`, `text-overline`, `tracking-overline`, `text-stat-value` (22px stat values). Light theme only.
- Data-service calls go to the browser-facing base `NEXT_PUBLIC_API_BASE_URL` (default `/curve-data`, `CURVE_DATA_PROXY_PATH` in `constants.ts`); `next.config.ts` rewrites `/curve-data/v1/:path*` to server-side `CURVE_DATA_SERVICE_URL` (default `http://localhost:10020/curve-data`). Never call the service address from the browser; never issue non-GET requests.
- Interactive controls use the `focus-ring` utility (white gap + Forest 400 ring); Shadcn `Button` already applies it.
- Fonts: IBM Plex Sans/Mono via `next/font/google` (self-hosted) exposed as `font-sans` / `font-mono`; `font-mono` gets tabular figures. Icons: `lucide-react` with `aria-hidden="true"` when decorative.
- Filtered lists re-key `DataState` by the applied filters, so a filter change reloads and returns to page 1; sorting and paging run in the browser over the whole loaded list.
- A 404 that has a specific "not found" message (BR6) is caught inside the `load` passed to `DataState` via `lookUp` and rendered with `NotFoundMessage`; every other failure is rethrown so `DataState` shows the persistent error with Retry. Downloads use `downloadFile` only (not the generated Blob helpers in `endpoints.ts`).
- Client components that read `useSearchParams` are rendered inside `<Suspense>` by their page.
- Every curve chart is a `LineChartCard` (series built in a `lib/` helper, series without data left out before passing them in); never a second chart wrapper or Recharts used directly in a view.
- Every read in a view goes through `DataState` (never a hand-rolled spinner or silent empty fallback); status labels use `StatusChip`; icon-only buttons use `IconButton`.
- Background re-checks (polling) use `DataState`'s silent-refresh props, never a second fetching mechanism or timer outside it; components that raise toasts need `ToastProvider` around them in tests.
- Shadcn CLI output must import `cn` from `@/lib/utils` and `Slot` from `@radix-ui/react-slot`; the CLI currently emits `from "cn"` / `from "radix-ui"` and adds those packages — fix the imports and revert `package.json`.
