
## Story 1: View a failed file's row-level errors

- Row-level errors now open inline in a Failed file's details, just below the action buttons. Choosing "View row-level errors" loads the failed rows for that file's full WOID. The grid shows Row number, Observation date and Message, sorted by row number first, and any column can be sorted. A row with no observation date shows a dash. A short note says row numbers count the original file's header rows. Download original stays in the same card.

- From manual-test feedback, the File log now scrolls to what you open. Choose a file in the list and the page scrolls to its details. Choose "View row-level errors" and the page scrolls to the grid. Scrolling is smooth, or instant if the system is set to reduce motion. Deep links and background refreshes do not move the page.
