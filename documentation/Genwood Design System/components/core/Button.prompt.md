Standard action button — use primary for the single main action of a view, secondary for everything else.
```jsx
<Button icon="upload">Import file</Button>
<Button variant="secondary" iconRight="download">Export CSV</Button>
<Button variant="ghost" size="sm">Cancel</Button>
```
Variants: primary | secondary | ghost | danger. Sizes sm 28 / md 36 / lg 44. Sentence-case labels, verb first.
