Renders a Lucide outline icon (1.5–2px stroke) tinted via currentColor — use for every glyph in Genwood UI.
```jsx
<Icon name="file-spreadsheet" size={16} />
<Icon name="triangle-alert" color="var(--status-warning-fg)" />
```
Loaded from lucide-static on unpkg via CSS mask. Sizes: 14 inline, 16 controls, 20 nav.
