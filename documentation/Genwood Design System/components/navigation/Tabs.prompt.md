Switches between views of the same object — line tabs for page sections, segmented for compact view toggles.
```jsx
<Tabs tabs={[{ id: 'all', label: 'All files', count: 42 }, { id: 'failed', label: 'Failed', count: 2 }]} />
<Tabs variant="segmented" tabs={[{ id: 'chart', label: 'Chart' }, { id: 'table', label: 'Table' }]} />
```
